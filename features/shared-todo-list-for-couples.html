Shared to-dos

A shared to-do list built for two people.

Put groceries, chores, errands and shared plans somewhere both partners can see—and give each task one clear owner.

Stop managing shared work through messages

Texting “can you remember this?” works until the message disappears under everything else. A shared list gives both partners the same source of truth: what needs doing, who owns it and when it matters.

One clear owner

Assign a task to yourself or your partner so “we should do this” becomes a clear next action without turning one person into the household manager.

Lists for real couple life

Keep groceries, household work, travel preparation and personal reminders organized without mixing every responsibility into one endless list.

Due dates and reminders

Add timing when it matters. Both partners can see what is coming up instead of waiting for a last-minute reminder.

Visible beside the week ahead

Important tasks appear alongside shared plans on Home, helping you understand what today requires without opening several separate apps.

A simple first-week setup

  1. Create one list that already matters. Groceries or household tasks are easier to adopt than an abstract “couple productivity” system.
  2. Add five real tasks. Include the small recurring things that usually live in memory or chat.
  3. Give each task one owner. Shared visibility does not help if responsibility is still ambiguous.
  4. Review the list together once. Keep what made life easier and remove anything that created more administration.
Tandem does not need to replace your personal task manager. Use it for responsibilities that affect both partners or require shared awareness.

Shared to-do questions

Can both partners add and complete tasks?

Yes. Once paired, both partners work from the same shared space and see updates to shared tasks.

Does Tandem work for an iPhone and Android couple?

Yes. Tandem is available on both platforms, so partners do not need to use the same type of phone.

Is Tandem only a task app?

No. Shared tasks live beside a couples calendar, manual expense tracking, routines and Weekly Sync.
